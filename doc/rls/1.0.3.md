# Release 1.0.3 – Remember Me & Brand Links

Patch release after 1.0.2. Everything below is backwards compatible.

* **Veronica: "Remember Me" Login**
  The Veronica login screen now offers an *Angemeldet bleiben / Remember me* checkbox. When checked, the login survives browser restarts: the app stores a remember record (`alias` + current PIN hash) in `localStorage` and auto-logs in on the next visit without any input.
  *Benefit: returning users skip the alias + PIN dance on their own devices.*

* **Remembered Logins Die With The PIN**
  The remember record stores the PIN hash that was valid at login time. On every app start it is re-verified against the synced user database - the moment a user's PIN is changed (by the user or an admin, on any device), every remembered login for that user becomes invalid: the app refuses the auto-login and deletes the stale record, showing the regular login screen. Explicit logout clears the remember record as well.
  *Benefit: "stay logged in" never outlives the credentials it was granted with.*

* **Vibe4Dock Wordmark Linked Everywhere**
  All visible "Vibe4Dock" brand marks are now clickable links to the product repository (`github.com/jbsnewmedia/vibe4dock-arcvd`): chat sidebar brand and footer, Veronica login brand line and app footer, Vibe-Diff footers (DE + EN) and the start page brand block. Existing links are untouched - the trailing "vibe4dock" in the footers still points to the umbrella repository, JBS New Media to jbs-newmedia.com - so every brand link has its own distinct target.
  *Benefit: from every UI there is now a one-click path to the source of the app you are using.*

**Compatibility:** drop-in for 1.0.2. No new environment variables, no schema changes - the remember record lives entirely in the browser's `localStorage`.
