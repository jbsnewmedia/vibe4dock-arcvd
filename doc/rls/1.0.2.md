# Release 1.0.2 – File Uploads & Mobile PWA

Patch release after 1.0.1. Everything below is backwards compatible.

* **File Uploads in Chat + Veronica (previously a known gap of the all-in-one image)**
  The 📎 attach button now actually works: uploads land in the project's `incoming/` directory and can be referenced in the prompt via `@filename` (the agent finds them by name). Veronica additionally serves an inline preview endpoint (`/api/upload/file?name=...`) for images, PDFs, audio and video already uploaded. Implementation: a small PHP endpoint (`/app/php/upload-api.php`, php-fpm) wired into the generated Apache routing - no tools container needed. Upload limits are raised to 100 MB per file (post 120 MB, execution 300 s); the target directory is created and permission-fixed at container start, optionally configurable via `VIBE_INCOMING_DIR`.
  *Benefit: photos, PDFs and documents reach the agent from every device - the upload buttons are no longer dead ends like in 1.0.1 and earlier.*

* **Mobile Attach Menu with Gallery Access**
  On touch devices the 📎 button opens a small action sheet instead of jumping straight into the file manager: **Choose file** (generic picker) and **Photos & videos (gallery)** (media picker via `accept="image/*,video/*"` - on Android this opens the gallery app, on iOS the photo library including a camera option). On desktop nothing changes (direct file dialog). Labels are fully translated (DE/EN).
  *Benefit: on phones, photos and videos no longer have to be dug out of the documents UI - the gallery is one tap away.*

* **PWA: Portrait Only, No Zoom**
  Both installable apps (Chat, Veronica) now request `orientation: portrait` in their manifest and set the viewport to `maximum-scale=1, user-scalable=no`. Already-installed PWAs pick this up after closing and reopening the app (manifest changes are re-read on launch).
  *Benefit: no accidental rotation or pinch-zoom states on phones; the UI stays in its intended layout.*

**Compatibility:** drop-in for 1.0.1. Uploads land in `<project>/incoming/` - if the project directory is a read-only bind mount, set `VIBE_INCOMING_DIR` to a writable path. No other new required environment variables.
