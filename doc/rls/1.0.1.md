# Release 1.0.1 – Bugfix Release

Patch release after 1.0.0, built from production experience with the five live instances on srv-docker. Everything below is backwards compatible.

* **Plan Mode Rework (Veronica)**
  Activating the toggle no longer sends anything - messages simply start running with opencode's `plan` agent. Deactivating sends the **GO** for implementation (default agent, user prompt text if present, otherwise a configurable plan-go phrase). New chats start with plan mode enabled by default.
  *Benefit: plan and build phases are cleanly separated - plan first, then a single explicit go.*

* **Fix: Veronica Models Were Unavailable (403)**
  The `models.json` alias lives below `/home/...` where Apache's `<Directory />` default denies access. With service auth enabled the location auth override masked this (chat worked), with auth disabled Veronica always received 403 - so favorites never showed. The generated location now carries an explicit access decision (service auth or `Require all granted`).
  *Benefit: Veronica's model menu (favorites, recent, all) works with and without basic auth.*

* **Retry for Cold opencode Starts (Chat + Veronica)**
  The `/config/providers` call can be slow/fail right after a container restart. Veronica now uses a 20 s timeout with two retries, chat retries twice as well.
  *Benefit: model menus recover automatically after restarts instead of showing "no models".*

* **Full i18n Coverage on the Language Switch**
  Chat: permission prompts, tool/error strings and the provider hint are translated. Veronica: open inline questions and pending permission boxes re-render on language change (signature guards include the language), the question input placeholder switches live.

* **Mobile Topbar (Veronica)**
  On small screens the Plan toggle is icon-only, the DE/EN switch moved into the chat actions menu (Person hinzufügen/entfernen, export, delete), and the status line shows text again beside the green dot.
  *Benefit: no overlap on small displays, topbar controls stay reachable.*

* **PWA Icons Legible**
  App icons regenerated with a cyan-dominant design (maskable variant with full-bleed cyan background) - no more near-black tiles on home screens.

* **Branding Links Corrected**
  All "Part of Vibe4Dock" footers link to jbs-newmedia.com

**Compatibility:** drop-in for 1.0.0. New/changed behaviour (plan mode go, mobile topbar) applies automatically; no new required environment variables.
